## Scenario and input

Synthetic PR: current head is new-b; checks for old-a passed, while the new revision has no result.

## 1. Set the ownership scope

Identify repositories, PRs and domain owners within authorized access, with one current follow-up owner.

## 2. Bind evidence to the current commit

Read the head SHA before checks and comments, keeping earlier passing results historical.

## 3. Classify blockers

Separate failed checks, conflicts, unanswered comments and missing information with links and next actions.

## 4. Review fixes and retesting

Propose repair scope and evidence, then recheck the new revision after any authorized fix.

## 5. Control monitoring and merging

Set normal and incident cadences with explicit owners and stop conditions, keeping merging and production actions under a separate policy.
