## 1. Check prerequisites

## 2. Handle credentials separately

## 3. Bound sender and task

Accept the paired sender and use an echo-only first test. Validate message type, size and identity before forwarding.

## 4. Trace each segment

Verify receipt, routine acceptance, completion and reply independently. Investigate an uncertain result before replaying the same identity.
