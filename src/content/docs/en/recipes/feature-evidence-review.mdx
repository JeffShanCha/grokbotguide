## Scenario and input

Synthetic requirement: selecting X shows X sources, clearing restores all items, and an unmatched query shows an empty state.

## 1. Define observable completion

Define entry, input, visible result, data changes and failure states rather than compilation alone.

## 2. Inspect the real environment

Read project instructions and existing processes, confirming commands, ports and scope before starting anything.

## 3. Prepare minimal acceptance cases

Provide success, empty-result and reset fixtures, keeping any project controls within authorized operations.

## 4. Collect evidence for one revision

Attach revision and time to tests, screenshots and logs; historical evidence does not establish current behavior.

## 5. Report coverage and gaps

Report pass, fail, untested and reproduction steps before deciding on commits, PRs or deployment.
