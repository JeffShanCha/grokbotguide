## Scenario and input

Synthetic notes: M1 proposes a Friday demo; M2 says the budget is unresolved; no owner is named.

## 1. Choose authorized material

Start with redacted notes or an authorized transcript and record the meeting date and coverage period.

## 2. Separate facts and actions

Separate opinions, decisions, proposals and actions, with a source location for each.

## 3. Expose missing fields

Mark absent owners, deadlines and budgets unspecified and collect them as clarification items.

## 4. Return a stable format

Return summary.md, actions.csv and questions.md before any external notification or calendar edit.

## 5. Repeat before reusing

Validate with a second note set, then save the stable rules. Review input refresh and ownership before scheduling.

## A synthetic acceptance fixture

actions.csv: item, owner, due, evidence, status. Mark the demo proposed, leave the owner unspecified, and preserve the unresolved budget.
