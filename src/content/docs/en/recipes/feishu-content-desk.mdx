## Scenario and input

Synthetic material: one read public X article and a designated test document.

## 1. Map the message path

Identify the group, app bot, relay, webhook routine and Grok Bot. Distinguish a group posting webhook from an app that subscribes to messages.

## 2. Check three permission layers

Check app scope, user or CLI identity and document sharing. Stop at the missing layer instead of broadening access.

## 3. Run one research item

Create a source record with its link and reading scope. The writer uses that record rather than inventing evidence.

## 4. Keep a task identity

Assign a task identity, suppress bot echoes and deduplicate events. Verify acceptance and completion separately.

## 5. Deliver to the test document

Deliver evidence, draft and questions to the test document for human review before production writing or publication.
