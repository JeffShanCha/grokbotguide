## Scenario and input

Synthetic material: one read public X article and a designated test document.

## 1. Map the message path

Identify the group, app bot, relay, webhook routine and Grok Bot. Distinguish a group posting webhook from an app that subscribes to messages.

## 2. Check three permission layers

Check app scope, user or CLI identity and document sharing. Stop at the missing layer instead of broadening access.

## 3. Run one research item

Create a source record with its link and reading scope. The writer uses that record rather than inventing evidence.

## 4. Keep a task identity

Assign a task identity, suppress bot echoes and deduplicate events. Verify acceptance and completion separately.

## 5. Deliver to the test document

Deliver evidence, draft and questions to the test document for human review before production writing or publication.

### Add four steps to the existing handoff table

1. **Specify the research window.** Give the coordinator a topic, sources and dates; require original links. The recording's contemporary research is an example from the author's date, not current reporting.
2. **Investigate one selected topic.** Keep the task identifier and have the researcher deliver evidence and unknowns. The writer consumes that artifact rather than starting unrelated collection.
3. **Deliver A/B drafts separately.** Use the same source set, identifying length, angle and unresolved claims. A short version still needs evidence.
4. **Record selection and sending separately.** Save the chosen version in the ledger; enter a platform action only under an explicit send instruction. The recording has no completed-send receipt, so its A/B selection wording does not establish an X post.
