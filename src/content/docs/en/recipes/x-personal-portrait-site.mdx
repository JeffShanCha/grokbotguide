## Prepare input you can inspect

You need a working Grok Bot and an existing Bot able to read attachments and create files. The sample exercise requires no X connection, hosting account or new API key.

1. Download `source.csv` above and attach it using the chat's attachment control.
2. Check that it has eight synthetic rows and the columns `id,date,text,url`. Empty URLs are intentional; these are not real posts.
3. Keep all outputs in one project directory. Use the actual absolute path returned by your Bot; a path on your Mac is not a path on its cloud computer.

Send this opening brief. It asks only for receipt and scope confirmation before later stages.

### Splitting the work between four Bots

One existing Bot can handle the roles sequentially. For ongoing specialization, use **New → Create new Bot** on desktop, then **Edit Profile** to set a name and role description.

| Role | Description to configure | Deliverable |
| --- | --- | --- |
| Source editor | Validate input and attribution; report missing or duplicate rows without personal inference | `source.csv` |
| Evidence editor | Make observations traceable to input and retain uncertainty | `claims.json` |
| Content designer | Organize approved observations for a first-time visitor | `site-brief.md` |
| Web builder | Implement approved files and report actual checks | `site/index.html` |

To form a group, select the Bots in **New chat**. Before each stage, use the `@` menu to select its owner, then paste the prompt. Typing a plain `@name` may not create an actual mention. Bots on one account can share computer files; separate roles do not isolate account permissions.

**Mention only the next owner at each handoff.** During our real group revision, mentioning both the designer and builder led to HTML being updated before the brief. The final files matched after review, but execution was not strictly sequential. To enforce the order, review the completed brief first, then assign the builder in a separate message.

## Step 2: map themes to evidence

Send this to the evidence editor. Look for themes in this writing, not personality scores.

## Common questions

**Can I do this without an X plugin?** Yes. Use the sample CSV or your own material that you may use. Collection is separate from evidence mapping and page creation.

**Can one Bot do it?** Yes. 二丫头 handled the synthetic exercise sequentially. The real-X run then reused four existing Bots to test group handoffs. Both produced the files; creating four new Bots is unnecessary for practice.

**Why no name or avatar in the synthetic sample?** Its input has no real identity, so the Bot should not invent one. The real-X observation also avoids the author's avatar so it does not resemble their own homepage. For your own page, provide the name and image you choose to make public and may use.

**Are these 蓝哥 AI's images or prompts?** No. We independently wrote these prompts and captured our own demo output. The inspiration is credited below.
