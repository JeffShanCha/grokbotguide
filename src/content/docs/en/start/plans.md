**Grok Bot is not sold separately. You get it through a paid Cursor plan, or by linking a SuperGrok subscription.** Prices change, so check the official pages before you buy.

## Eligible plans

| Channel | Plans | Notes |
| --- | --- | --- |
| SuperGrok | SuperGrok, SuperGrok Plus, SuperGrok Heavy | Individual subscription, linked to a Cursor account |
| Cursor individual | Every paid individual plan | For example Pro, Pro+, Ultra |
| Cursor Teams | Teams Standard, Teams Premium | Self-serve team seats |
| Enterprise | Contact your Cursor account team | Rolling out |

Key points from the official FAQ:

- Subscriptions include **weekly usage**. Eligible accounts can add on-demand usage billed by model and token cost.
- If you have both Cursor and SuperGrok, Grok Bot uses **whichever has more usage left**.
- Grok Bot usage is separate from your other Grok or Cursor limits (launch announcement).

:::caution[Check current pricing]
On launch day VentureBeat reported $200/month for individuals via Cursor Ultra, $120/seat/month for teams via Cursor Premium Teams, and $300/month for SuperGrok Heavy. These numbers may change.
:::

## What this site uses

All hands-on testing on this site is done with a **SuperGrok** subscription, so screenshots and usage notes reflect that. If you already pay for Cursor, you can use that account instead.

## Linking SuperGrok

1. Sign in to the Grok Bot app with a Cursor account (create one if needed).
2. On desktop, open **Settings → Usage & Billing** and select "Link SuperGrok …" (the label shows your tier).
3. On mobile, tap **Link Grok Account** when prompted, then **Finished Linking? Refresh My Status**.

:::note
Grok Bot requires cloud data storage. If your Cursor account uses "Legacy Privacy Mode", switch to a supported data setting first.
:::
