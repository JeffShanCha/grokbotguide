## Scenario and input

Synthetic goal: a main Bot handles one research request and returns three sourced points.

## 1. Define the main role

Explain intake, clarification and concise reporting in chat. Start with role proposals rather than automatic roster creation.

## 2. Run one fixed task

Use explicit input and acceptance criteria, checking that the original source was actually read.

## 3. Check connector identities

Verify account and scope in the current connection interface, then use a small read-only test. Manage external authorization separately from a Bot's existence.

## 4. Distinguish CLI environments

Record whether a CLI runs locally or in the cloud, its identity and its allowance. Use its supported authentication flow rather than copying sessions.

## 5. Add triggers last

After stable manual results, propose skills or triggers with timezone, duplicate handling and stop conditions.
