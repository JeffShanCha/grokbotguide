## Scenario and input

## 1. Bound the backup

List the selected roles, accessible definitions and project files, separating shared material and excluding credentials from ordinary snapshots.

## 2. Export accessible material

Export only accessible material and inspect the actual artifact rather than relying on a completion message.

## 3. Write the manifest and restore guide

Record source, scope, time, path and checksum, explicitly listing omitted history, sessions and installed software.

## 4. Run a bounded restore drill

Verify readability and checksums in a separate test directory, then reconstruct one synthetic role brief without overwriting real state.

## 5. Schedule after acceptance
