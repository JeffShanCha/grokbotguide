Adapted from the scheduled-routine example in the official docs. It assumes you already have a skill called "Daily customer-risk" (see [Weekly account health skill](/en/templates/weekly-account-health/) for how to write one).

<CopyTemplate id="daily-customer-risk">

```text
Create a routine:
- Owning Bot: <your customer-success Bot>
- Schedule: every weekday at 08:00, time zone <America/New_York>
- Action: run the "Daily customer-risk" skill against the current account list
- Output: post a linked watch list in this conversation
- Boundary: do not contact any customer
- If a source is unavailable: report a failure; do not use old data
Before creating it, repeat these settings back to me for confirmation.
```

</CopyTemplate>

## Checklist

After creating it, do one **Test run** (it does real work) and confirm:

- It used today's data
- The output matches the format
- It took no external action
- It reports a failure when a source is down instead of silently skipping
