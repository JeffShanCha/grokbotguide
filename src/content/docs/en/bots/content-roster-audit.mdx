## Scenario and input

Synthetic roster: researchers A and B collect the same brief; writer C has no output directory.

## 1. Inventory deliverables

Record known inputs, artifacts and ownership, marking unavailable evidence rather than inferring capability from titles.

## 2. Find overlaps and breaks

Compare research scope, topic ownership and review roles, marking duplicate collection and missing or competing owners.

## 3. Separate execution and acceptance

Identify drafting, factual checking and publication approval, keeping separate records even if one person fills several roles.

## 4. Propose the smallest change

Prefer a skill or handoff adjustment and document the routines and files affected by any proposed roster change.

## 5. Retest one input path

Retest one research-to-draft path before adding monitoring; quiet reporting still leaves checking costs.
