### Turn the role into five delivery steps

1. **List the inputs.** Supply an exact Markdown path, title, cover and expected image list, with draft creation as this run's limit.
2. **Check execution conditions.** The recording uses a third-party skill and browser automation. Its repository and scripts were not obtained or reviewed, so no installation command can be reconstructed from the name. With a trusted implementation, inspect commands, execution location and affected files first.
3. **Check asset completeness.** Report copy failures individually. Copying ten images does not establish that all ten reached the editor.
4. **Let the user handle sign-in.** Use the computer takeover card for login and verification, then return control, following the [official takeover guidance](https://cursor.com/docs/grok-bot/work). Account details and verification codes are omitted.
5. **Review the draft receipt.** Include the draft link, title, cover, expected and actual image counts, missing assets and unfinished work. An 8/10 result needs repairs and another preview before a separate publication decision.
