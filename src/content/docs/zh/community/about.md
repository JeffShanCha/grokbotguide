**GrokBotGuide 是一个独立的、社区共建的非官方项目，与 xAI、SpaceXAI、Cursor 没有隶属或授权关系。** Grok 及相关名称是其各自所有者的商标，本站仅为说明用途提及。

## 我们怎么写内容

- 官方事实一律链接到官方原文；我们用自己的话写教程，不整段翻译官方文档。
- 外部内容只收录标题、我们写的摘要、原文链接和作者署名，不转载原文和图片。
- 每篇文章标注内容分级和最后验证日期。

## 修改与下架

如果你是某条收录内容的原作者，希望修改或下架，请发邮件到 [takedown@grokbotguide.ai](mailto:takedown@grokbotguide.ai)，或在 GitHub 提 Issue。我们承诺 72 小时内处理，原作者要求下架的直接删除。
