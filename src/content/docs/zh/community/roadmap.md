**待写选题都在 GitHub Issues 里，打了 `good first article` 标签的最适合第一次投稿。**

| 阶段 | 目标 | 状态 |
| --- | --- | --- |
| 第 1 周 | 双语骨架、部署上线、投稿流程 | 站点已上线；投稿表单和复制计数待配置 |
| 第 2–3 周 | 种子内容：每种语言约 40 篇教程、角色卡、模板和实战案例，逐篇亲测后更新标注 | 进行中：内容已发布，目前都整理自官方文档或社区分享，亲测尚未开始 |
| 第 4 周 | 公开推广，第一篇外部 PR 合并 | 未开始 |
| 第 2–3 个月 | 模板库筛选与复制计数、贡献者榜、每周更新日志 | 未开始 |

## 优先需要的内容

- 实战案例：Gmail、Shopify、Google Search Console、X 账号运营
- 角色卡：招聘、投放优化、费用管理、跨境客服、出海 SEO
- 进阶：用量与成本控制、团队版配置、排障手册
