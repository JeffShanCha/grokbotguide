**Grok Bot 不单独售卖，有两条获取渠道：Cursor 付费套餐，或关联一个 SuperGrok 系列订阅。** 价格会变，下单前请以官方页面为准。

## 可用的订阅

| 渠道 | 包含的套餐 | 说明 |
| --- | --- | --- |
| SuperGrok | SuperGrok、SuperGrok Plus、SuperGrok Heavy | 个人订阅，需要关联到 Cursor 账号使用 |
| Cursor 个人版 | 所有付费个人套餐 | 例如 Pro、Pro+、Ultra |
| Cursor 团队版 | Teams Standard、Teams Premium | 自助购买的团队席位 |
| 企业 | 联系 Cursor 客户团队 | 正在逐步开放 |

几个关键点（来自官方 FAQ）：

- 订阅内含**每周用量**，符合条件的账号可以再加按量计费的用量（按模型和 token 计费）。
- 如果你同时有 Cursor 和 SuperGrok，Grok Bot 会使用**剩余用量更多**的那一个。
- Grok Bot 的用量独立计算，不占用你在 Grok 或 Cursor 里的其他额度（官方发布公告）。

:::caution[价格以官方为准]
发布当天 VentureBeat 报道的参考价：个人通过 Cursor Ultra 为 $200/月，团队通过 Cursor Premium Teams 为 $120/席/月，SuperGrok Heavy 为 $300/月。这些数字之后可能调整。
:::

## 本站怎么选

本站的实测统一使用 **SuperGrok** 订阅完成，文章里的截图和用量感受都基于它。如果你已经是 Cursor 付费用户，可以直接用 Cursor 账号，不需要再买。

## 关联 SuperGrok 的步骤

1. 在 Grok Bot 应用里用 Cursor 账号登录（没有就先注册一个）。
2. 桌面端打开 **Settings → Usage & Billing**，点击「Link SuperGrok …」（按钮文字会显示你的档位）。
3. 移动端在提示时点 **Link Grok Account**，完成后点 **Finished Linking? Refresh My Status**。

:::note
Grok Bot 要求开启云端数据存储。如果你的 Cursor 账号开着「Legacy Privacy Mode」，需要先切换到支持的数据设置。
:::
