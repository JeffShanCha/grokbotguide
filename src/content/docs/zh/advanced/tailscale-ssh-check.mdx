先分清私网连接与 SSH 授权，再核对目标主机、系统用户和撤销路径，用只读命令验证连接。

原文通过 Tailscale 将本机接到云电脑，并演示 SSH。本文将作者环境中的用户名与地址改成待核对参数，不承诺固定配置或持续在线。

## 场景与输入

先列 client、target、os_user、ssh_mode、allowed_scope、revoke_method，不在普通笔记记录私钥。

## 1. 确认目标与范围

记录两台设备的所有者与目标目录；需要安装客户端或改访问策略时先由本人确认具体影响。

## 2. 完成设备授权

按当前 Tailscale 官方方式登录并确认控制台设备身份，不复制来源文章的真实地址、令牌或账号参数。

## 3. 选择 SSH 模式

传统 SSH 走 Tailscale 私网，与 Tailscale SSH 代管认证是两种配置。后者需网络与 SSH 规则同时允许。

## 4. 只读验证主机与目录

先检查主机身份提示，再用 whoami、pwd 等只读命令确认实际用户与目录，不先改生产文件。

## 5. 留恢复与撤销方案

记录连接失败停点、设备撤销方式和另一条合法恢复路径；不把 SSH 端口直接开放公网来补救。

## 一份合成验收样例

两项独立验收：网络能到目标；指定身份可进入指定用户。Tailscale 网络连通不等于系统 SSH 已启用。

## 验收与复核

主机、用户和目录与计划一致；访问可撤销；云电脑休眠、重建和策略变动需重新检查。
