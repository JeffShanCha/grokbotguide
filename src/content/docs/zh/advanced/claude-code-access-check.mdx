## 场景与输入

合成检查单：一台计划使用的电脑，账号类型尚未确认，无任何真实支付信息。

## 1. 说明来源差异

保留原嵌入链接和实际主题，不拿其他文章补成所谓额度说明；下面的操作依据为官方资料。

## 2. 核对支持条件

从当前官方安装页确认系统、网络、地区与账号要求，无法满足时记录阻塞。

## 3. 分开认证与计费

记录用订阅账号登录还是获准使用 API、费用由哪一账户承担；不要把终端已安装当成已有额度。

## 4. 由本人完成认证

按官方流程安装和登录，密码、验证码与付款由本人处理；保存状态信息，不保存验证短信或卡号。

## 5. 先做最小验证

从版本与认证状态开始，再在测试目录做低成本只读任务；未实际验证的项保持待测，不做账号稳定性保证。
