把采集窗口、累计数据、增量阈值和通知状态分开，先离线比较两次样本，再讨论定时与存档。

## 场景与输入

合成快照：P1 在 08:00 为 4,000 次浏览，09:00 为 10,000；演示阈值为每小时增加 5,000。

## 1. 固定观察范围

明确账号名单、公开来源、时间窗口与白天/夜间规则；不可用数据先报告，不承诺抓到所有帖子。

## 2. 建立带时间快照

保存 post_id、observed_at、views 和读取状态，按原帖 ID 去重；相同时间的快照不能当成两个采样点。

## 3. 写清阈值口径

区分累计值、增量与单位时间增长；本文样本用差值除以小时数，缺基线时不触发增长告警。

## 4. 验证通知去重

同一帖子和规则只发一次，记录 pending、sent、unknown；发送结果不明先查回执，不立刻重发。

## 5. 单独确认存档与定时

先交本地样本结果；GitHub 文件范围、是否公开、提交和推送、Routine 频率分别确认。外部模型也有自身计费条件。

## 一份合成验收样例

P1 的一小时增量为 6,000，触发一次。只有 10,000 累计值而无前次快照时，不能推算小时增速。alert_key 使用 post_id 与规则版本。

## 源码补充：先对齐扫描规则，再验收阈值与失败轮次

原文指向的 [aehyok/x-viral-monitor](https://github.com/aehyok/x-viral-monitor/blob/8ad0a750c4f794036c4e946aca655eadf55e100d/README.md)已核对，固定版本 `8ad0a75`。公开内容是可读的 Skill、Routine 提示词、状态与归档，**没有独立采集脚本或安装器**；仓库未见许可证声明。这里补充文件支持的规则，不将文字流程称作已跑通的程序。

### 五个可落实的操作点

1. **分开扫描与调度。** [Skill 输入](https://github.com/aehyok/x-viral-monitor/blob/8ad0a750c4f794036c4e946aca655eadf55e100d/skill/SKILL.md#L12-L39)由调用方提供账号、阈值、回看窗口、时区与状态路径；[Routine](https://github.com/aehyok/x-viral-monitor/blob/8ad0a750c4f794036c4e946aca655eadf55e100d/routine/PROMPT.md#L3-L22)另设北京时间 06:04–23:04 的小时窗口，06:04 只建基线，不推送。复用时先把自己的参数与时间表列清楚。
2. **用实际间隔算相邻快照。** 已有快照时，两份文件都用浏览差值除以实际间隔小时数，严格大于 5,000 才达标。两个小时多了 6,000 次只等于每小时 3,000 次，不能当作 6,000 次。
3. **明确首次观测采用哪条规则。** [SKILL.md 59–65 行](https://github.com/aehyok/x-viral-monitor/blob/8ad0a750c4f794036c4e946aca655eadf55e100d/skill/SKILL.md#L59-L65)对首次帖龄取至少 1 分钟；[PROMPT.md 18–20 行](https://github.com/aehyok/x-viral-monitor/blob/8ad0a750c4f794036c4e946aca655eadf55e100d/routine/PROMPT.md#L18-L20)取至少 1 小时。5 分钟前发布、1,000 次浏览，分别会算成 12,000/h 与 1,000/h，结论相反。本文合成练习继续用“首次只建基线”，不把两条源规则混成一种，也未替作者修订仓库。
4. **把读取失败和零命中分开。** [0909 失败归档](https://github.com/aehyok/x-viral-monitor/blob/8ad0a750c4f794036c4e946aca655eadf55e100d/data/hourly/2026-10-13/0909.json#L37-L41)记录 `x_read_unavailable`、检查 0 帖且保留旧快照。没有新命中不等于取数成功；回执应保留失败账号、错误和上次有效观测时间。
5. **对齐状态、通知和归档的版本。** 已通知 ID、快照和每小时结果分别保存，通知不明不能冒充已送达。当前 commit 把账号精简为 2 个，旧归档仍保留当轮 12 个，这是历史配置；回查时用当轮名单。源文件描述了 Git 归档，但没有独立实现证明写入、通知与推送具备原子性。
