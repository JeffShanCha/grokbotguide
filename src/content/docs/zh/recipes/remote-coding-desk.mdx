## 场景与输入

合成任务：在测试目录读 README，返回三个事实和引用位置；不改代码、不推送。

## 1. 先核对软件与身份

确认官方安装来源、版本、受支持账号与执行主机，授权和付费由本人完成；不用来源里的其他人凭据。

## 2. 先通私网再通界面

确认设备与访问规则，再按当前 Orca 文档建立受保护的远程会话；来源里的端口和配对链接只作环境示例。

## 3. 单独检查 CLI 状态

记录运行位置、账号、版本与授权状态；缺少授权就停，不修改配置来掩盖登录失败。

## 4. 执行最小只读任务

用测试 README 检查终端输入、输出回读与引用路径；把发出命令、结束和结果通过分成不同状态。

## 5. 验证更新恢复

记录软件更新或电脑重建前后哪些包、服务和会话需要恢复，保留回滚路径；定时自检先出草案。

## 一份合成验收样例

connection-check.md 分四层：network、remote_session、cli_identity、task_result。能打开远程界面不代表 Claude 已登录或任务已完成。
